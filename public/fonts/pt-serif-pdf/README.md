PT Serif TTF files embedded by the direct browser PDF exporter.

Source: Google Fonts `ofl/ptserif`.
License: SIL Open Font License 1.1; see `OFL.txt`.

The PDF renderer requires TTF or WOFF input, so these files are separate from the WOFF2 subsets
used by the HTML editor preview. Keep all four styles together for Latin and Cyrillic output.
